# Architecture

This repository owns the mlemes Claude Code marketplace catalog and installation documentation. Plugin code stays in mlemes/quotaline and mlemes/ml-referee. Each catalog entry uses a GitHub source with a full commit SHA; update pins after validating the corresponding release. No plugin runtime, hooks or dependencies live here.

This is the only marketplace catalog. The marketplace name is mlemes; plugin identifiers are quotaline@mlemes and ml-referee@mlemes.
